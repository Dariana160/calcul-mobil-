Fashion Mirror 👗

Descriere: Fashion Mirror este o aplicație Android care permite utilizatorilor să creeze și să personalizeze ținute vestimentare folosind un avatar 3D.

Obiective:

Explorarea articolelor vestimentare.

Personalizarea hainelor pe un avatar 3D.

Salvarea ținutelor preferate.

Preluarea datelor dintr-un API extern.
